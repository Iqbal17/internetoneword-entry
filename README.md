One word for the whole internet, funniest and most fitting wins. The program writes exactly one word — "doomscrolling" — to entry.txt: the one activity every app, feed and argument on the internet converges on, and the accusation the reader is committing while they read it. The gate allows 1 to 30 characters of UTF-8 text; the entry is a single correctly spelled word of 13 characters and nothing else.

## Run it

```sh
python3 main.py
```
